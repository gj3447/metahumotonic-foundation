# 결정 기록 (변경 영수증)

모든 MHP 결정은 여기에 `MHP-0000-제목.yaml` 로 남습니다.
형식은 [PROPOSALS.md](../PROPOSALS.md) 의 "결정 기록" 절을 따릅니다.

- `ACCEPTED` 뿐 아니라 `REJECTED` / `DEFERRED` / `WITHDRAWN` 도 남깁니다.
- 보존된 반대 의견(`dissent`)은 지우지 않습니다.
- 이 기록이 없는 변경은 무효입니다.

아직 공개 절차가 완료된 MHP 결정은 없습니다.

완료된 것처럼 채우지 않습니다.
