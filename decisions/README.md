# 결정 기록 (변경 영수증)

모든 MHP 결정은 여기에 `MHP-0000-제목.yaml` 로 남습니다.
형식은 [PROPOSALS.md](../PROPOSALS.md) 의 "결정 기록" 절을 따릅니다.

- `ACCEPTED` 뿐 아니라 `REJECTED` / `DEFERRED` / `WITHDRAWN` 도 남깁니다.
- 보존된 반대 의견(`dissent`)은 지우지 않습니다.
- 이 기록이 없는 변경은 무효입니다.

아직 공개 절차가 완료된 MHP 결정은 없습니다.

## 사용자 지시로 적용한 로컬 변경

- [2026-10-07 MHL-1.1과 CHU 참여 원칙](2026-10-07-chu-membership-license.json):
  공개 라이선스에 지정한 하드웨어의 전체 관리 권한 공유와 “CHU의 일부가 된다”는 의미를 추가.
  기존 1.0 허락·원문을 보존하며, 공개 RFC 비준과 현재 기기 접근 승인은 별개입니다.

- [2026-10-03 MetaHumotonic License 적용](2026-10-03-metahumotonic-license.yaml):
  사용자 지시에 따른 작업트리 라이선스 변경. 공개 RFC 비준이나 배포 완료 기록이 아닙니다.

이 기록은 MHP 결정과 구별하며, 공개 검토·커밋·발효가 완료되지 않은 필드는
완료된 것처럼 채우지 않습니다.
